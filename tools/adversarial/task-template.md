# Task

## Goal

Describe the observable problem and the intended resulting behavior.

## Acceptance criteria

- Give a reproducible starting state, action, and expected result.
- Identify edge cases that could break the change.
- Name relevant PLAYER_EXPERIENCE.md criteria for gameplay work.

## Evidence required

needed in addition to the three mandatory project checks. If human judgment is
required, say what should be prepared for review.

## Scope

State which behavior should change and any design decisions already settled.
Reference relevant entries in decisions.md. Avoid combining unrelated features.
